# v0.2.0 E2E Usability Plan

## Goal

Add an official, reproducible end-to-end demo that exercises the real Shadiff CLI across `record -> replay -> diff -> report` using HTTP plus MySQL, PostgreSQL, and MongoDB side effects.

## Scope

- Add a Docker Compose demo under `examples/e2e/`.
- Include old/new demo APIs that return matching HTTP responses but produce different DB side effects.
- Provide a one-command runner that builds Shadiff, runs the full workflow, writes artifacts, and optionally asserts expected differences.
- Keep LAN hostnames, SSH details, and private paths out of the repository.
- Do not change Shadiff CLI flags, config schema, or DB hook interfaces.

## Approach

1. Start MySQL, PostgreSQL, MongoDB, old API, and new API with Docker Compose.
2. Run `shadiff record` with DB proxies and send one request through the recording HTTP proxy.
3. Run `shadiff replay` against the new API with replay DB proxies.
4. Run `shadiff diff` to write JSON output and `shadiff report` to write HTML output.
5. Assert that artifacts exist and JSON diff contains SQL and MongoDB side-effect differences.
